# Hamster Archiver v4.4.8

## 自动更新修复

- 修复更新器把新版 `resources`、`tools` 等目录复制成同名嵌套目录的问题。
- 更新过程现在先备份旧程序项，再删除对应旧项并精确写入新版；启动验证失败时仍会恢复旧版本。
- `userdata` 始终排除在程序替换范围之外，设置、仓库、缩略图和日志不会因程序升级被覆盖。
- 增加真实 PowerShell 回归测试，确认旧文件被清理、新目录不会嵌套、现有便携数据保持不变。

## 4.2.0 用户注意

4.2.0 的手动更新说明写在该版本自身程序中。它能发现和校验新 Release，但内置的旧替换脚本无法正确覆盖已有程序目录，因此必须按弹窗步骤手动升级一次。完成这次手动升级后，后续版本将使用修复后的更新器。
