# Hamster Archiver 4.5.3

4.5.3 是基于 4.5.2 的兼容性维护版本，重点加强便携更新、仓库搬迁恢复、用户数据位置保护和开发工具链兼容性。

## 主要变化

- 顶部新增“选择更新包”，可直接选择新版 Windows x64 发行 ZIP。程序会拒绝同版、旧版、平台不符、清单无效或关键文件被破坏的压缩包。
- 本地 ZIP 更新复用现有自动更新的程序替换、回滚和启动验证流程，始终排除现有 `userdata`、仓库与归档包。
- 仓库缩略图统一保存为相对于当前仓库的引用；旧绝对路径会在启动、切换仓库或导入时安全升级，仓库移动或改名后仍可显示、删除和撤销图片。
- 用户数据位置文件损坏、缺少有效目录、指向磁盘根目录或目标消失时会明确停止，不再静默创建一个空用户区。
- 源项目与仓库、压缩暂存目录或归档成品目录互相包含时会拒绝处理，防止仓库内容被重复扫描或后处理误伤。
- 普通开发支持 Node.js 22.12+（22.x）和 24.x，正式发行仍固定 Node.js 22.23.2/npm 10.9.8；npm 包统一从官方仓库锁定并验证完整性。
- 本地发行会自动准备仓库外的固定 Node.js 22.23.2/npm 10.9.8 工具链，系统安装 Node.js 24 时也能直接运行，无需手动切换或修改系统环境。
- 内置 7-Zip 与 FFmpeg 继续严格核对关键二进制版本、大小和 SHA-256，同时要求许可证与来源说明文件存在并纳入发行包完整性清单。

## 便携版更新提示

可以在程序顶部选择官方发行 ZIP 进行升级，也可以继续使用 GitHub 自动更新。升级前请等待归档任务结束；更新器只替换程序文件，不覆盖现有 `userdata`。
