# Hamster Archiver 4.5.5

4.5.5 是基于 4.5.4 的相似度准确性、数据安全与界面文案修复版本，重点解决真实仓库中的陈旧重复标签和短名称误导，并落实第三方核查中能够复现的高风险问题。

## 主要变化

- 单字母、单汉字、纯编号等低信息名称不再单独形成标题或目录相似证据，也不会把 `P` 之类的目录整行标红。
- “可能重复”只表示当前仍存在的相似关系。历史入库时记录的名称重复或精确重复原因继续作为审计信息保留，但不会在对应项目已经不存在后继续显示标签。
- 用户手动移除的相似关系仍是持久排除项，全局或单项重算不会擅自恢复；系统现在正确保留最近 200 条排除记录。
- 全量重算使用稳定目录快照和本次计算专属的词频统计，目录增删或其他相似度操作不会再污染正在进行的重建。
- 快速切换仓库详情时，较早返回的数据不会覆盖后来选中的项目。
- 归档后处理与更多设置删除冗余说明，队列提示改为“多选可进行批量操作”；中英文词典同步更新。
- 五套主题的仓库活跃度格子统一使用与明暗背景适配的绿色渐变。
- 程序化退出会先安全停止运行中的队列再关闭数据库；异常压缩体积确认后的回收站处理也会执行同一套安全熔断。
- Windows 回收站还原只允许明确识别出的“还原/恢复”动词，不再尝试未知的第一个菜单操作。
- 用户数据与旧目录跨盘复制后会核对文件、目录和总字节；跨盘移动清理原位置失败时保留完整目标副本并给出人工核对提示。

## 数据与更新说明

本版本不改变仓库数据库格式、缩略图引用或用户数据位置。升级后执行一次“全局重算”即可主动清理旧版本留下的陈旧相似标签；应用启动时也会因相似算法版本升级在后台维护旧关系。手动排除记录会继续保留。
