# Hamster Archiver 4.5.4

4.5.4 是基于 4.5.3 的兼容性与界面完善版本，修正相似度重算、目录标记、运行时 i18n 和应用内更新入口，并统一开发与本地发行使用的 Node.js/npm 支持范围。

## 主要变化

- 修复全局重算已经完成、仓库也已保存后，进度条仍停留在 98% 等最后分片进度的问题。最终完成事件现在会推进到 100%，显示实际用时后自动收起。
- 新进度到来时会取消旧的隐藏计时器，避免连续执行全局重算时，上一轮计时器提前隐藏当前进度。
- 相似度强度标题不再重复显示“标准”等当前档位，滑杆刻度继续保留宽松、标准、严格三档说明。
- 相似度排除词表和全局重算操作区改用项目统一的嵌套面板底色与边框，不再使用单独的米黄色样式。
- 重算后没有相似项目的条目会移除“可能重复”；名称重复和精确文件重复仍保留独立风险标记。
- “完整目录结构”重新支持在 Windows 路径中标红相似目录名和文件名；任务生成完整清单后的二次判断也会使用当前相似度强度。
- 队列中的相似提示、确认状态、预计时间以及 7-Zip 调用日志现已完整支持英文；用户数据区的系统选择和重启确认窗口也会跟随界面语言。
- 新增低饱和东方浅色“青瓷”和深梅紫夜色“暮紫”两个主题。
- “检查更新”窗口始终列出当前版本与最新版本；有新版时提供自动更新，并在任意检查结果下保留“手动更新”ZIP 入口，顶部不再重复放置独立按钮。
- 开发和本地发行支持 Node.js 22.12+（22.x）或 24.x，以及 npm 10.x/11.x；`.nvmrc` 与 CI 跟随 Node.js 24.x，本地发行直接使用当前受支持的运行时，不再下载第二套 Node。
- 发行清单记录实际使用的 Node.js/npm 版本；npm 锁文件以及内置 7-Zip、FFmpeg 的版本、大小和 SHA-256 校验保持不变。

## 便携版更新提示

从 4.5.3 升级不会改变现有 `userdata`、仓库、缩略图或归档包。应用内“检查更新 → 手动更新”或 GitHub 自动更新都会继续校验版本、平台、发行清单和关键文件完整性。
