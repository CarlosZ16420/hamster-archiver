# Hamster Archiver v4.4.7

## 修复

- 修复暂停/恢复控制无响应时可能长期等待的问题；超时后会安全取消当前任务并停止队列。
- 仓库导入和导出改为异步执行，避免大型仓库操作冻结界面。
- 相似关系重算分批让出界面线程，并缓存仓库缩略图摘要，降低大仓库状态刷新开销。
- 增加队列状态停滞熔断，避免异常分支重复执行同一个任务。
- 更新包版本校验统一兼容带 `v` 前缀的 Release 标签。

## 更新提醒

4.2.0 及更早版本仍检查旧的公开 Release 渠道。如果旧版本没有发现更新，请按照 README 中的手动迁移步骤复制完整 `userdata`；不要只替换 EXE。
