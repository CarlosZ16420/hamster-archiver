# Hamster Archiver 4.5.17

4.5.17 修复队列重复确认的异步状态问题，统一“内容完全一致 / 项目完全重复”的用户表达，并补齐安装版的更新与安装体验。

## 主要变化

- 任务进入“已自动跳过”或“重复待确认”后，核心层会清除旧的清单进度，界面层也会拒绝跨阶段的过期进度。状态标签不再停留在“生成清单与 MD5”，点击队列也不会让确认请求消失。
- 文件级证据统一称为“内容完全一致”，完整项目统一称为“项目完全重复”。重复项处理菜单、确认按钮、日志、报告和中英文翻译同步更新。
- 整个项目完全重复时，相似报告直接显示“项目完全重复”；部分证据会分别列出内容完全一致的文件、名称完全一致的目录和名称相似项。
- 相似报告和仓库完整目录结构共用的目录树现在会同时用金色标出一致文件的文件名和 MD5。
- 新配置默认开启超大文件夹简化处理、极小文件 MD5 跳过和自动跳过；默认阈值为 500 个文件、200 个代表文件和 5 KB。完成后移动到指定位置默认关闭。
- 安装版可从 GitHub 读取更新内容，自动下载并校验 Setup EXE；联网失败时仍可手动选择更高版本安装程序。更新完成后的首次启动也会显示本次更新内容。
- 安装程序会把目标规范为所选父目录下的 `Hamster Archiver` 子目录，提供“创建桌面快捷方式”选项，并从完成页直接启动已安装 EXE。稳定应用标识会识别已有安装并执行升级，避免重复安装。

## 数据与安全说明

本版本不改变 SQLite 结构或用户数据位置。队列默认值只影响新配置或此前未保存该选项的配置，不覆盖用户已经明确保存的选择。自动更新只接受 GitHub Release 中名称与版本匹配的安装程序并校验 SHA-256；手动安装更新只接受严格命名且高于当前版本的 Setup EXE。
