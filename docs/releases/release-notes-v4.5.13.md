# Hamster Archiver 4.5.13

4.5.13 正式收口 4.5.12 标签之后的队列安全、相似报告、主题与仓库交互改进，并修正版本标签、代码和发行说明曾经不同步的问题。

## 主要变化

- 用户主动检查更新时会先看到新版本内容；在线更新或手动发行 ZIP 更新成功后，新版本首次启动会再次显示本次摘要，后台静默检查仍不会主动打扰用户。
- “卡顿规避”的超大文件夹阈值默认改为 500，极小文件阈值默认改为 5 KB；抽样不再参与整项目精确重复定案，完整归档和自动跳过始终使用独立完整证据。
- 同一路径且文件路径、大小、修改时间均未变化时可以安全复用已有 MD5；不同路径候选仍会补齐实际 MD5 后严格比对。
- 相似报告未生成 MD5 时只快速展示名称与大小证据，之后复用队列或仓库清单；精确重复使用金色文件名提示，名称相似使用可点击的红色片段，完全一致的项目名和目录名会明确显示为完全一致。
- 修复库内项目压缩误触发重复核验、自动跳过拖入时不执行、重复继续入口缺失、报告与当前项目自身比较，以及同源未压缩项目不能复用 MD5 等问题。
- 用户数据区路径改为只读安全切换；仓库单项整理和批量追加标签共用按中英文逗号分段的自动补全，并支持 Tab 接受建议。
- 仓库文本列表当前项与多选项使用绿色状态底色，普通悬停与普通目录使用中性色；精确重复、名称相似、成功、警告和危险提示的颜色语义不再混用。
- “森林”和“暮光”替代原“青瓷”和“暮紫”，并统一五套主题的正文、次要文字、焦点、成功、警告、危险、信息与中性提示色。
- 高级压缩设置把密码选项移到格式选项之前；本次进一步把虚线分隔恢复到“压缩格式”上方，并对齐“记录解压密码”“分卷压缩”的勾选框和标题。
- 仓库搜索框清空、点击原生清除按钮或在空栏按回车后都会立即恢复完整结果。
- 选择或打开仓库列表项、卡片时不再整块重建结果列表；异步读取新详情时保留原详情高度，消除页面闪烁与跳动。
- 项目详情标题与所在面板使用相同底色；顶部品牌图标改用项目已有的原生 32×32 ICO 帧，避免超大 PNG 非整数缩放造成模糊。

## 数据与安全说明

本版本不改变 SQLite 表结构或用户数据位置。卡顿规避仍不会减少压缩内容；自动跳过只在完整项目身份得到严格确认后执行。现有 4.5.x 用户可使用完整 Windows x64 便携 ZIP 或安装程序升级。
