# Hamster Archiver 4.5.15

4.5.15 进一步明确扫描、相似提示和精确重复核验的职责，并将相关修复整理为可供测试的便携版本。

## 主要变化

- 拖入或扫描目录时只做名称、路径、文件数量和大小等快速预检，不会读取所有文件内容或预先计算 MD5。
- 名称、标题或视频大小相似只表示“疑似相似”，任务会先等待人工确认，不会因此被当成精确重复取消，也不会越过确认直接入库。
- 用户选择入库方式并启动队列后，才会生成内容 MD5。只有完整相对路径、文件大小和有效 MD5 全部一致，才会自动跳过精确重复。
- 当前任务为精确核验补齐的 MD5 会保存到待处理清单，确认后继续时直接复用；库内未压缩项目压缩和后续相似报告也会优先复用已有清单。
- 不同目录的旧项目核验会先按路径和大小筛选，再按小文件优先、发现不一致即停止的方式读取内容；单次读取量不超过一个当前项目，证据不足时改为人工确认。
- 扫描只生成队列，定时运行不会启动尚未选择入库方式的任务；定时时段外的等待原因和具体跳过原因会写入“运行日志”。

## 数据与安全说明

本版本不改变 SQLite 结构或用户数据位置。精确重复自动跳过只改变当前队列项：可按设置保留为“已跳过”或从队列移除，不会删除源文件，也不会改动仓库内已有项目。
