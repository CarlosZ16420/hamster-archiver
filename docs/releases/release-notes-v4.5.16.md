# Hamster Archiver 4.5.16

4.5.16 重整了“相似提示—精确核验—自动跳过”的操作顺序，并为大型仓库加入持久化项目指纹与批量查询，减少无意义确认和重复读取。

## 主要变化

- 扫描或拖入时发现名称、标题或视频大小相似，只在队列中给出候选提示，不再阻止用户选择入库方式。
- 队列启动并生成当前项目的完整内容清单后，只有完整相对路径、文件大小和有效 MD5 全部一致才会认定为精确重复；开启自动跳过时会直接按设置跳过，不要求用户先确认一次相似关系。
- 不属于精确重复、但存在名称或文件级相似证据的项目，只在完整清单生成后显示一次相似确认；确认结果与本次清单指纹绑定，继续时直接复用，源文件变化不会错误继承旧结论。
- SQLite 新增项目形状指纹和内容指纹索引。旧仓库首次打开时会自动迁移并补齐索引，先缩小候选范围，再做严格比较。
- 跨目录旧项目需要补算内容时，会优先读取能够最快排除候选的文件；候选全部排除后立即停止。相似报告中的精确文件证据改为分批查询，不再对每个文件单独扫描仓库。
- 暂停当前任务后可直接在队列工具栏取消；超大文件夹的代表文件数量可设置，默认 200。

## 数据与安全说明

本版本把本地 SQLite 结构升级到版本 3，并从已有记录自动生成项目指纹；原记录、缩略图、归档文件和用户设置不会被移动或删除。项目指纹只用于候选筛选，最终精确重复判断仍会复核完整清单，不能仅凭哈希索引删除或修改任何仓库内容。
