# Hamster Archiver 4.5.11

4.5.11 调整收存目录配置，并为队列加入严格的完整项目自动跳过能力。

## 主要变化

- “需备份目录”改为选填；未设置时点击“扫描目录”会弹出目录选择窗口，确认后保存该目录并立即扫描。
- “压缩后保存在”仍为正式归档的必填位置；压缩暂存目录默认在该位置旁建立 staging 目录。
- 队列工具栏新增“设置”，可开启精确重复项目自动跳过，并选择跳过后保留或删除对应队列项。
- 自动跳过只接受完整项目级一致：文件数量、相对文件名、文件大小和 MD5 必须全部相同。只有部分文件相同、同名或标题相似的项目仍需人工确认。
- 跳过不会修改源文件或仓库；即使删除队列项，运行日志仍会保留处理结果。
- 完整目录结构不再为普通可展开目录使用红色整行背景，仅保留实际相似名称片段的标红和白名单入口。
- 修复“需备份目录”说明气泡被左侧设置栏边框裁切的问题，并精简队列提示文案。

## 数据与更新说明

本版本不改变 SQLite 数据结构或用户数据位置。新增设置会以安全默认值关闭自动跳过；升级后可在队列“设置”中主动开启。现有 4.5.x 用户可使用完整 Windows x64 便携 ZIP 或安装程序升级。
