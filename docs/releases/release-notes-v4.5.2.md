# Hamster Archiver 4.5.2

4.5.2 以 4.5.0 的完整界面与功能线为基础，合并了中英文界面完善、新版相似度算法，以及工具链和发布流程的维护成果。

## 主要变化

- 完善中英文界面、动态提示和原生对话框翻译，并补充词典与静态覆盖校验。
- 重写相似度计算：改进中文分词、词频权重、多证据融合、排除词缓存和批量重算进度。
- 保留 4.5.0 的设置布局，相似度功能区移除重复边框和标题。
- 切换相似度强度不会自动重算已有关系；需要更新全库关系时，请手动点击“全局重算”。
- 锁定 Node.js、Electron、npm 依赖、7-Zip 和 FFmpeg 工具版本，并加强构建完整性校验。
- 开发维护目录与真实用户数据彻底分离；本地 current、ZIP、历史构建和开发数据不再混入源码根目录。
- 新增版本、目录和发布安全检查，以及可回滚的本地 current 构建提升流程。

## 便携版更新提示

请完整解压新版运行文件，不要只替换 `HamsterArchiver.exe`。程序代码位于同目录的 `resources` 中；只替换 EXE 会继续加载旧版界面和逻辑。升级时保留原有 `userdata`，其中包含设置、仓库数据库、缩略图和日志。
