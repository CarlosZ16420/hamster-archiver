# Hamster Archiver 4.5.6

4.5.6 是相似度准确性、仓库筛选和公开项目主页维护版本。它根据真实仓库的只读逐项回放收紧了误报来源，并让用户可以直接聚焦需要人工核对的项目。

## 主要变化

- 仓库标签筛选新增“可能重复”，无需先创建同名标签，即可筛出当前仍有有效相似关系的项目。
- 标题相似度改用双向加权覆盖率，不再因为短标题的全部词元恰好出现在长标题中而得到虚高分。
- 标准与严格档不允许单个孤立共享词独立形成重复关系；常见题材词、画质词、翻译格式词和同一作者名不会再单独定案。
- 相似算法版本升级到 6。升级后应用会在后台重建旧关系并清理误报“可能重复”标签，用户手动解除的双向排除记录保持不变。
- GitHub 项目主页采用与应用一致的暖米色、炭黑、仓鼠橙和安全绿色视觉，新增可编辑 SVG 主视觉与归档流程图，并重新组织中英文功能、更新、数据安全和开发说明。

## 真实仓库核验

本轮以只读方式检查了 166 条生产仓库记录、25 个已标记项目和 20 条现存相似关系，并逐项对照标题、视频名、文件大小和 MD5 证据。旧算法留下的多数关系只有泛词或格式词重合，没有同大小或同摘要文件；新版回放保留 4 条高相关关系，涉及 5 个项目。生产数据库在核验过程中没有被修改。

## 数据与更新说明

本版本不改变 SQLite 数据格式、缩略图引用和用户数据位置。首次启动后的后台相似度维护只更新关系字段；如需立即看到全部新结果，也可在设置中主动执行一次全局重算。手动排除结果不会被重新加入。
