# Hamster Archiver 4.5.7

4.5.7 是仓库浏览、相似度白名单入口和本地发行稳定性的补丁版本。

## 主要变化

- “完整目录结构”中由名称相似产生的红色片段可以一键加入相似度白名单；首次操作会说明影响并支持关闭后续提醒。
- 文件夹项目的完整目录树重新显示原始主目录名称，内部目录、文件路径和相似定位逻辑保持不变。
- 仓库文本列表增加备份位置列，并支持使用键盘左右方向键翻页；输入控件和对话框不受影响。
- 相似度“全局重算”按钮保持单行显示；无入库记录的活跃度日期使用白色，与未来日期的透明状态明确区分。
- 本地发行脚本在 Windows 权限环境拒绝 Node 目录改名时提供受限的系统原子改名后备路径，并继续保留旧 current 与发行包的回滚机制。

## 数据与更新说明

本版本不改变 SQLite 数据格式、缩略图引用、相似关系结构或用户数据位置。加入白名单后只刷新当前项目详情，不会自动重算整个仓库；需要清理既有关系时可主动执行单项或全局重算。
