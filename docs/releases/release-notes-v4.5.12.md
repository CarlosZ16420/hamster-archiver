# Hamster Archiver 4.5.12

4.5.12 为包含海量文件的目录新增可选“卡顿规避”，降低 MD5 和文件级相似度计算带来的等待与内存压力。

## 主要变化

- 队列“设置”新增“卡顿规避”分组，默认关闭，不改变升级前的处理行为。
- “超大文件夹简化处理”可填写文件数阈值，默认 800；超过阈值时选取 200 个代表文件记录 MD5、计算文件级相似度。
- 抽样结果稳定可重复：100 个名额优先覆盖体积较大的内容，另 100 个名额沿完整路径清单均匀分布，兼顾主要文件和不同子目录。
- “MD5计算跳过极小文件”可独立启用；小于 64 KB 的文件先被排除，之后再从其余文件中补足代表样本。
- 自动跳过说明精简为“自动跳过已经完整存在于仓库中的项目”，并明确抽样或跳过 MD5 后不会把部分清单误当成完整重复项目。
- 新功能、日志、校验错误和说明均已覆盖简体中文与英文。

## 数据与安全说明

卡顿规避只减少 MD5 和文件级相似度参与量，不会减少压缩内容。应用仍保存全部文件的相对路径、大小与修改时间，压缩包仍包含完整目录；压缩前后的源文件变化检查和 7-Zip 完整性校验保持不变。设置只影响新加入队列的任务，任务入队后会保存当时的阈值与开关，避免运行中修改设置改变既有任务。

本版本不改变 SQLite 表结构或用户数据位置。现有 4.5.x 用户可使用完整 Windows x64 便携 ZIP 或安装程序升级。
