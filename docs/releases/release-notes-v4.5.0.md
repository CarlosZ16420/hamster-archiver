# Hamster Archiver 4.5.0

本版本集中修复更新迁移、路径设置和相似度判断问题。

## 主要变化

- 更新失败时，手动升级将明确引导用户先在旧版导出仓库，再在新版并入外部仓库，不再推荐直接搬动 `userdata`。
- “更多设置”中的用户数据区和压缩暂存目录现在都可以手动选择，选择结果会保存。
- 用户数据区切换采用保守策略：空目录会复制耐久数据且保留旧目录；已有 Hamster Archiver 数据的目录会直接切换，不进行隐式合并。
- 未压缩项目执行压缩升级时，不再把自己的已完成入库任务判为相似项目。
- 删除仓库项目后，其已完成任务历史不再参与新任务的重复和相似度判断。
- “使用说明”移到页面右下角；运行记录标题不再重复最新日志内容。

## 手动升级

如果自动更新失败，请在旧版本中“导出仓库”，完整解压新版到新目录并运行，再使用“并入外部仓库”导入刚才导出的压缩包。确认仓库记录和缩略图正常前，请保留旧程序目录。
