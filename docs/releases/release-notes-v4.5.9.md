# Hamster Archiver 4.5.9

4.5.9 是项目主页、双语说明与公开视觉素材的维护版本。

## 主要变化

- 中文 README 保留原有正文和顺序，补齐三处真实界面视觉，并加入中英文切换入口与致谢。
- 英文 README 依据中文版本重新编排和翻译，功能、数据边界、更新方式与开发入口保持一致。
- 三组视觉均提供独立中英文版本，覆盖归档工作台与大缩略图仓库、仓库概览、项目整理信息、媒体预览和完整目录结构。
- 视觉素材使用隔离构造数据，裁去本机绝对路径、截断控件和不完整列表行；没有提交原始媒体、仓库数据库或用户数据。

## 数据与更新说明

本版本不改变 SQLite 数据结构、用户数据位置、归档流程或相似度算法。现有 4.5.x 用户可以直接使用完整 Windows x64 发行 ZIP 更新，`userdata` 不参与程序文件替换。
