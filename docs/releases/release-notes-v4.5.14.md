# Hamster Archiver 4.5.14

4.5.14 修复深色主题菜单，并收紧扫描、重复确认与精确重复判定边界。

## 主要变化

- 黑夜与暮光主题中的主题下拉选项不再出现白底浅色文字。
- 每个选项同时使用当前主题的字段背景和正文色，经典、白昼与森林主题也保持一致的原生控件配色。
- 增加界面回归检查，防止主题选择菜单再次遗漏选项前景色或背景色。
- “扫描目录”只把项目加入队列；用户选择压缩或不压缩入库后，定时器才可以启动这些任务。
- 名称、标题或视频大小相似会先进入等待确认；精确重复要求本次任务的有效 MD5 与完整仓库清单严格一致。
- 扫描完成后不再残留“正在统计”提示，未入队内容会明确区分小项目过滤、非视频文件、链接和读取失败。
- “运行记录”更名为“运行日志”，定时时段外的入库选择和等待原因会留下日志。

## 数据与安全说明

本版本不改变 SQLite 结构或用户数据位置。升级后，尚未选择入库方式的新扫描任务不会被定时器自动启动；现有 4.5.x 用户可直接使用便携 ZIP 或安装程序升级。
