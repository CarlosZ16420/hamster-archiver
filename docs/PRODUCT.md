# 产品说明

Hamster Archiver 是 Windows 本地优先的批量归档与可搜索媒体仓库。它先把一级目录或视频扫描为独立任务，由用户明确选择压缩入库或不压缩直接入库；生成清单并验证后写入 SQLite 仓库，再按用户选择处理源文件。

## 核心承诺

- 源文件安全高于自动化速度；验证未完成时不执行破坏性后处理。
- 用户资料、媒体、密码与仓库数据库默认只保存在本机。
- 压缩包、仓库记录、缩略图和原文件状态能够相互追溯。
- 名称与相似关系只提供候选提示，不替代用户决策；开启自动跳过后，完整项目通常仍需严格内容证明。唯一的元数据快捷规则是：仓库记录与当前任务指向同一原始位置，并且完整文件路径、大小、数量、总大小及目录结构（含空目录）全部一致；缺失或跳过内容的旧清单不能使用该规则。
- 应用可便携运行，但开发仓库不承担用户数据目录或安装目录职责。

## 主要领域

- 归档工作台：扫描、队列、压缩、验证和源文件处理。
- 仓库：搜索、预览、编辑、导入导出和恢复。
- 相似度：生成候选、计算关系、排除词和人工解除。
- 设置：数据位置、压缩参数、工具路径、语言与主题。

默认首页是仓库；空仓库会提供可跳过、可永久关闭的首次归档引导。未压缩记录再次使用压缩入库时，若已有备份位置与本次设置冲突，用户可以明确决定更新记录或保留原值。
- 更新：由用户主动检查新版，在替换前展示更新内容，并在校验、替换、启动验证与失败回滚后，于新版本首次启动时回顾本次变化。

## 非目标

- 不负责把压缩包上传到云盘。
- 不把媒体或数据库上传到在线分析服务。
- 不在公开仓库直接开发。
- 不让源码根目录 EXE 充当“当前安装版本”。

用户可见行为变化应同步更新 README、CHANGELOG 和对应发行说明。
