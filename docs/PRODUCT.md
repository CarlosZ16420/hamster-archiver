# 产品说明

Hamster Archiver 是本地优先的批量归档与可搜索媒体仓库。Windows 提供正式版，macOS 提供公开 Beta。它先把一级目录或视频扫描为独立任务，由用户明确选择压缩入库或不压缩直接入库；生成清单并验证后写入 SQLite 仓库，再按用户选择处理源文件。

## 核心承诺

- 源文件安全高于自动化速度；验证未完成时不执行破坏性后处理。
- 用户资料、媒体、密码与仓库数据库默认只保存在本机。
- 压缩包、仓库记录、缩略图和原文件状态能够相互追溯。
- 名称与相似关系只提供候选提示，不替代用户决策；开启自动跳过后，完整项目通常仍需严格内容证明。跨位置项目即使文件完全相同，只要目录结构（含空目录）不同，也不是完整重复。唯一的元数据快捷规则是：仓库记录与当前任务指向同一原始位置，并且完整文件路径、大小、数量、总大小及目录结构全部一致；缺失或跳过内容的旧清单不能使用该规则。
- Windows 版可便携运行；Mac 版使用标准应用包和用户的 Application Support 目录。开发仓库不承担用户数据目录或安装目录职责。
- 实验性 AI 接入默认关闭；启用后，CLI、MCP 与桌面 UI 调用同一应用任务服务、队列与核验流程。AI 接入不表示程序内置在线内容识别模型，也不会赋予网页聊天访问本机文件的能力。
- AI 后台任务提供系统托盘或菜单栏入口，并在共享工作台标明来源；用户可以随时查看、暂停或安全接管。断线不会重复提交已登记的同一请求。

## 主要领域

- 归档工作台：扫描、队列、压缩、验证和源文件处理。
- 队列以用户明确启动的固定批次执行；运行和暂停期间仍可扫描、拖放、手动添加或从仓库加入任务，新任务保留在“待启动”区域。当前批次支持 1—3 项并发，内存不足或来源、仓库记录、输出发生冲突时只延后新任务，不扩大或改写已确认范围。Mac 上首项已明确启动的任务不因系统对可回收缓存的低空闲内存读数而无限等待，后续并发仍受内存门槛约束。
- 仓库：搜索、预览、编辑、导入导出和恢复；本次运行中的条目删除可连同 Windows 回收站文件撤回。
- 相似度：生成候选、计算关系、排除词和人工解除。
- 设置：数据位置、压缩参数、工具路径、语言与主题。
- AI 接入：正式高层 CLI、紧凑 MCP、统一任务状态与保留回执，以及可单独启停的宿主适配；危险动作继续使用产品级影响确认。

默认首页是仓库；空仓库会提供可跳过、可永久关闭的首次归档引导。未压缩记录再次使用压缩入库时，若已有备份位置与本次设置冲突，用户可以明确决定更新记录或保留原值。
- 未压缩目录支持“校对更新”：执行时以一次完整扫描同时得到文件与目录快照；仅新增内容可自动并入，修改、删除或旧快照不完整必须先由用户查看变化并选择覆盖、新建独立项目或跳过。正式提交前保留原仓库内容；校对更新不修改、移动或删除原文件，二次压缩仍在成功提交后沿用用户既有后处理设置。
- 压缩位置可在保存设置、添加任务和不压缩入库时留空；真正启动压缩前必须选择有效位置。桌面原生选择器取消不会启动或改写任务范围。
- 压缩成品先传到最终位置，再在那里执行一次完整性测试与清单核对；暂存文件保留到验收完成。原文件后处理只能使用本次验收凭据，历史时间戳不足以授权删除。
- 跨盘源移动校对完整相对路径、逐文件大小及空目录后才移除原件；跨盘恢复校对当前移后内容并保留移后副本，可在详情查看其位置。结构校对不等同于逐字节内容校验。
- 仓库导入只复制新增记录引用的图片并以新名称保存；完整重复导入不改现有资源。导出在目标同盘生成并测试临时 ZIP，成功后才替换原备份。
- 同一规范化目录位置已有未压缩记录时，再次添加该目录必须进入更新或压缩语义，不能默认为独立新项目；用户仍可在变化确认中显式新建独立项目。未变化文件复用已有 MD5 与预览，新增或变化文件才重新读取、计算和生成预览。
- 未压缩记录已被待处理或运行中的更新、压缩任务绑定时，删除该记录会逐项拒绝并提示先完成或取消任务；先删除记录后再接收同一源项目则按新项目扫描。异常恢复中的旧任务若发现记录已不存在，保留原请求结果并给出取消后重新接收的明确错误，不自行改绑。
- 更新：Windows 版由用户主动检查新版，在替换前展示更新内容，并在校验、替换、启动验证与失败回滚后，于新版本首次启动时回顾本次变化。Mac Beta 仅提供发行页下载和手动替换应用。

macOS Beta 的源文件扫描跳过符号链接，路径重叠判断兼顾常见的大小写不敏感和 Unicode 归一化卷；同卷判断使用文件系统设备身份，空间检查使用系统可用字节数。Mac 不提供 Windows 回收站相关的删除、复原和撤回文件能力，归档后可以保留或移动源文件。视频抽帧默认关闭；用户配置可用的 FFmpeg 后可启用。

## 非目标

- 不负责把压缩包上传到云盘。
- 不把媒体或数据库上传到在线分析服务。
- 不在公开仓库直接开发。
- 不让源码根目录 EXE 充当“当前安装版本”。

用户可见行为变化应同步更新 README、CHANGELOG 和对应发行说明。
