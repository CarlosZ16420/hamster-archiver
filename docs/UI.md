# UI 与 i18n 约束

当前 4.5.x UI 信息架构是后续修改的基线：工作台、队列、仓库和设置各自只保留一个主容器与一个主标题。历史原型位于 `docs/prototypes/new-ui/`，只用于参考，不能作为运行入口。

## 修改原则

- 先复用已有卡片、字段和对话框，不嵌套重复的功能框或标题。
- 用户可见文案必须通过 i18n 键提供中英文，不在业务逻辑中散落硬编码文本。
- i18n 动态模式默认保留捕获到的标题、标签、路径、用户输入和系统原始错误；只有明确属于应用界面的捕获片段才允许递归翻译，避免误改用户资料。
- 队列阶段、预计时间和日志属于运行时文案，必须使用阶段文本翻译通道；由多个片段组成的内容按 ` · ` 分段匹配，不能只依赖整句静态词典。
- 运行日志在启动时恢复当前用户数据区最近 300 条有效记录；界面必须继续区分日志文件无法读取或写入的状态。设置变更只展示字段名称，不能显示密码值；普通搜索、浏览、复制和打开位置不进入运行日志。
- Electron 原生对话框不经过 DOM 翻译，必须根据当前语言显式提供中英文按钮、标题、说明和错误消息；主进程动态错误可复用无 Electron 依赖的共享 i18n 模块，但不得翻译路径或用户资料。
- 启动时的联网更新检查保持静默；只有用户主动点击“检查更新”才展示新版和更新内容。在线更新与手动 ZIP 在替换前都展示说明，成功启动新版本后再展示一次，并按当前界面语言选择中英文内容。
- 打包应用在完整性检查期间显示轻量启动窗口，跟随已保存的中英文与主题设置；首次或缓存失效时显示真实校验进度，失败时保留可关闭的错误界面。普通桌面主窗口可在仓库完整清单仍由后台线程分批加载时先显示，但必须明确展示加载数量、暂时禁用仓库筛选与选择，不得把未加载状态显示成空仓库或启动新手引导；依赖完整仓库的操作统一等待加载成功。MCP 后台与验收入口仍以完整仓库就绪为准。
- 中英文切换不重建用户数据，不改变任务状态。
- 应用首次启动且尚未保存语言时，中文 Windows 使用中文，其余 Windows 界面语言使用 English；此后始终沿用用户已保存的选择。应用启动后默认进入仓库。仓库为空且用户未关闭引导时，显示六步新手引导：第一步在解释空仓库的同时显示固定双语的 `语言/Language`、`中文`、`English` 选择器，切换后原地刷新并保存，不增加单独步骤；随后依次聚焦“归档工作台”、整块收纳设置、唯一必填的压缩包位置、原文件后处理与顶部状态、队列操作和拖放区。收纳设置步骤优先把提示卡放在高亮区域右侧，每一步都可跳过，“不再提示”写入用户设置。正常完成后只播放一次短暂的烟花与非品牌 emoji 庆祝效果。
- 仓库概览的库存数量与 GB 容量是同一个历史统计入口；月视图按日展示并可纵向翻阅到最早入库年份，年视图提供年度汇总。统计只读取现有仓库记录，不触发全库重算。
- 仓库概览的“标签”指标打开与记录统计一致的全屏标签视图；视图列出“可能重复”“未压缩”和全部用户标签及各自项目数，点击任一标签后关闭视图、进入仓库并应用对应筛选。
- 仓库活跃度展示截至当前周的最近 20 周，默认直接看见最右侧的最新日期；方格尺寸与列间距始终固定，宽容器不拉伸，只有窄容器确实放不下时才出现横向滚动条。用户停留在最新端时，窗口缩窄后仍自动保持最新端可见。
- 随机漫步没有项目封面时使用主题默认渐变；白昼主题使用森林的绿金渐变。空仓库也展示同一背景，但不显示“暂无封面”占位文字。
- 顶部“仓库 / 归档工作台”导航在桌面宽度下以窗口中心为锚点，不受左右两侧控件宽度变化影响；窄窗口进入独立整行布局后仍保持居中。
- 控件只绑定一次事件；渲染函数重复执行不能叠加监听器。
- 仓库切换项目立即显示当前加载状态，失败显示可重试提示；媒体靠近可见区域才读取，最多同时读取 4 张。不能把设置图片 `loading=lazy` 当作已限制 IPC 文件读取。
- 视频抽帧缩略图保留原始画面比例，不在图片文件中写入黑边或其他补边；固定比例卡片使用完整前景与模糊背景呈现，避免裁切真实画面。
- 需要长时间运行的操作必须由用户显式触发，并展示范围、进度和取消/失败状态。
- MCP 后台启动提供 Windows 托盘入口，不抢占前台焦点；托盘显示连接、运行或待确认状态，可打开现有归档工作台和选择“当前工作结束后退出”。托盘不可创建时核心接入仍可继续并记录诊断。
- AI 创建的任务在现有队列表格中显示“AI 提交 / AI request”来源标记并保留 requestId 提示，不新增第二套队列。关闭由托盘打开的窗口时回到托盘；普通桌面启动保持原有关闭行为。
- “更多设置”中的“实验功能 → AI 助手接入”默认关闭；Codex Skill、Codex MCP、WorkBuddy、通用 MCP 和 Windows ODR 预览分别显示真实状态并可单独启停。界面必须说明元数据会进入所选 AI 客户端上下文；配置冲突或用户修改只提示修复，不覆盖或删除用户内容。ODR 缺少 package identity 时显示安全限制，不引导降低 Windows agent connector 保护。
- 扫描目录只负责生成队列；新任务显示“待选入库方式”，必须由用户明确选择压缩入库或不压缩直接入库后，手动运行或交给已启用的定时时段执行。队列运行期间仍允许扫描、拖放和单项添加；新加入项目显示“等待下次入库”，待当前运行结束后再处理。
- 名称、标题或视频大小相似在拖入或扫描后显示为非阻塞候选提示；用户选择入库方式并启动队列后再生成本次任务指纹。完整一致且已开启自动跳过时直接跳过；只是相似或核验不完整时，统一在指纹生成后显示一次明确确认。该确认必须绑定当前清单，继续时复用已生成清单，源文件发生变化后不得沿用。
- 修改相似度强度只保存后续计算参数，不自动全库重算；单项或全库重算使用独立动作。
- 队列相似报告复用仓库的虚拟目录树：名称相似只在可点击加入白名单的实际匹配片段上使用红色，文件内容完全一致或目录名完全一致使用柔和金色底和文字标记；内容一致时文件名与 MD5 同时标金。金色优先且不得与红色重叠，不使用连续整行外框；普通目录的名称、展开图标、静止底色和悬停底色全部使用中性色。从报告跳转仓库后，返回工作台应恢复原报告。
- 队列“卡顿规避”中的超大文件夹简化处理和极小文件 MD5 跳过均默认开启；超大文件夹阈值默认 500，代表文件数量默认 200，二者均可调整。启用后明确说明只抽取用户设置的 N 个代表文件参与 MD5 和文件级相似度。极小文件阈值默认 5 KB 且可以按 KB 调整。项目完全重复自动跳过默认开启；“完成后移动到指定位置”默认关闭。
- 当前任务暂停时，队列主工具栏必须同时提供“继续当前任务”和“取消当前任务”，不能只依赖需要横向滚动才能看到的行末操作。
- 卡顿规避不得把未抽样文件排除出名称、路径和大小诊断，也不得阻止同一路径未变化项目的自动跳过；一键加入白名单必须先用应用内可编辑确认框展示最终词汇，确认后才写入排除词表。
- 仓库单项“整理信息”和批量追加标签共用同一自动补全逻辑：按中英文逗号识别当前标签片段，从已有仓库标签中推荐，排除本次已填写标签，并允许用 Tab、Enter 或鼠标接受建议。
- 库内未压缩项目再次压缩时，如果原记录与当前设置都有且使用不同的备份位置，单项确认直接列出原位置和当前位置；批量可保留原位置、逐项确认或更新并继续。逐项确认只阻塞位置不同的任务，队列行提供“确认备份位置”，其他任务正常执行；位置选择随任务保存，不随后续设置变化。备份确认不能替代大任务风险确认。
- 未压缩目录详情提供“更新目录”“压缩入库”，原文件位置的“打开”旁提供“修改”，批量操作提供“批量更新目录”。目录更新应立即建立只包含本批项目的任务并开始检查，不受定时窗口限制；不可更新的选中项须明确排除。已在更新或压缩队列中的项目须提示先完成或取消任务。重新定位只改记录路径，下次更新或压缩时再核对内容。无变化时 Toast 显示“项目名与本地目录内容一致”，项目名保留前 15 个字符并按需加省略号，日志保留完整项目名。Toast 位于右下角返回按钮上方。
- 目录变化报告必须显示新增、修改、删除的文件与目录，并提供“覆盖原项目”“新建独立项目”“跳过”。修改、删除、旧快照不完整及压缩前发现的任意目录变化都必须停在该报告；仅新增内容可自动更新。报告只读取任务执行时保存的对比数据，打开弹窗不得再次遍历目录。
- 同一路径已有未压缩项目时，再次拖入或选择该目录显示“待选入库方式”，选择不压缩即更新原项目，选择压缩即升级原项目；只有在变化报告中显式选择“新建独立项目”才建立并列记录。
- 单项选择、拖放或粘贴因“小项目过滤”被拒绝时，界面必须展示去除 IPC 包装后的同一条可读错误，自动展开“入库与预览”、滚动到“小项目过滤”并短暂高亮对应卡片。
- 批量拖放或粘贴中有多个项目低于小项目阈值时，界面使用一条合并提示并显示当前阈值；运行日志仍按项目名称逐条记录跳过原因。
- 已配置的压缩包存储位置不存在时，开始压缩前必须让用户选择创建原位置、重新选择或取消；归档引擎不得静默重建缺失的成品目录。
- 工作台“收纳设置”默认展开并允许整体折叠；“01 · 收纳设置”在视觉上与“02 · 扫描与队列”基本对齐，并只高出数个像素，运行日志条目与扫描队列控件的左边界一致。仓库概览的活跃度与随机漫步卡片下边缘对齐。页脚在短内容页面贴近窗口底部；顶部主导航只有在控件确实放不下时才进入独立行。
- 危险动作说明对象、影响和恢复方式，默认按钮不能指向不可逆操作。
- 删除仓库条目时，对应本地压缩包和图片进入 Windows 回收站；当前运行的撤回历史可恢复文件与完整条目，退出后不保留应用内恢复副本。删除或撤回尚未收尾时关闭窗口，界面先退出视线，进程完成当前短操作后再结束。
- 应用内弹窗统一使用接近 Windows 窗口的小圆角；右上角关闭控件只显示“×”，不使用带“关闭”文字的按钮。检查更新弹窗标题左侧显示项目 Logo，底部操作区使用更明确的主题分层和带边框、阴影的按钮。

## 仓库整理交互

- 文本列表与缩略图共用记录 ID 选择状态。正文普通点击仍打开详情并记录范围锚点；复选框切换单项。Ctrl 点击正文或复选框切换单项且不打开详情；Shift 点击按当前页排序选择连续范围，Ctrl+Shift 追加范围；无有效锚点时只选择目标项。
- 左键拖动超过 6px 后启动框选，两种视图都支持从正文或空白开始；普通框选替换选择，Ctrl 框选对命中项反选，Shift 框选追加。每次手势以按下时的选择快照计算；接近窗口上下边缘自动滚动。输入控件与独立动作不启动框选，完成后不触发详情点击；Esc、失焦、指针取消或内容重绘取消手势并恢复原选择。
- 普通空白点击和非弹窗/输入环境下的 Esc 清空全部选择；项目区域获得焦点后 Ctrl+A 全选当前页。顶部全选控件在当前页全选后可取消全部跨页选择，不再重复提供独立清空按钮。翻页与视图切换保留选择、重置范围锚点；搜索或筛选变化清空选择，排序变化仅重置锚点。计数明确标出不在当前页的已选数量。
- 顶部复选框根据当前页显示空框、横杠或对勾；空框/半选点击补齐当前页并保留跨页选择，全选点击清空所有页选择。控件不显示旁边的重复说明，通过悬停提示和可访问名称提供“全选当前页”或“取消全部选择”，空页禁用全选，已有选择可直接清空。
- 缩略图视图按钮使用大、中、小三态 SVG 图标，默认中档并保存在本机界面偏好；已在缩略图视图时再次点击按大→中→小→大循环，悬停缓慢呼吸，减少动态效果时停用动画。切换仅改变卡片密度，不改变每页数量、页码、选择或详情，不重生成图片；列表模式不受影响。卡片封面始终贴住顶部，不随同排项目文字高度居中；紧凑卡片保留可读文字、可操作复选框与完整画面，长文本省略，标题和备份位置可悬停查看。列表标签列渲染全部标签，移除与大小/状态列重复的未压缩标签；超长、过多标签在该列边界裁切，不遮挡备份位置等后续字段。
- 分页直接在“第 N / 总页数 页”的 N 位置使用无上下微调按钮的可编辑页号，不再提供重复的“跳到”框；点击或聚焦显示可滚动的页码候选，候选可通过鼠标或上下方向键与 Enter 接受，Esc 关闭并恢复当前页。直接编辑后 Enter 或失焦提交；越界整数收敛到第一页或末页，空值和非整数恢复当前页。列表表头与数据共用列宽和内边距，窄窗口下同步隐藏相同字段。
- 列表名称列提供独立的一键复制按钮，复制当前展示的完整项目名称，不打开详情、不改变选择；表头与行内容共用列宽和默认 20px 列间隔，不叠加单元格水平内边距。所有表头左对齐，正文文件数量右对齐，其他文字左对齐。默认前七列按照名称、类型、文件数量、大小/状态、标签、备份位置、入库时间的 293:40:37:72:214:168:97 比例分配可用宽度，并保留最小可读宽度；星级固定 64px，不使用旧偏好中包含尾部空白的宽度。窄窗口隐藏字段后共用同一套列边界，最后一个可见字段保持固定显示宽度。
- 列表表头分界线使用很浅的细线，拖动可用分界线时，从右侧其他可调整列借出或归还空间，表格总宽及末列的位置和宽度始终不变；紧邻末列的分界线固定，不能拖动。表头与正文实时同步，偏好保存为相对比例，兼容读取旧列宽设置；翻页、视图切换、窗口变化与重启后继续按可用宽度分配，禁止拖动撑宽表格或把末列推出可视区域。双击可拖动分界线或聚焦后按 Home 恢复默认比例，左右方向键微调，Shift 加大步长。Esc、失焦、指针取消、窗口尺寸变化或内容重绘取消当前拖动并恢复原比例；拖动不改变项目选择，不打开详情。极窄容器优先缩减列间隔，再按比例缩小最低宽度，仍将末列保留在视野内。
- 仓库搜索框随可用宽度收缩，为筛选、视图和仓库工具留出空间；鼠标点击或键盘聚焦后在原位展开至正常搜索宽度，不推动其他工具换行。队列的五项状态统计在窄窗口下仍保持同一行。
- 仓库批量操作栏固定为全选框、选择计数与操作组、撤回与手动新增组；计数与批量按钮保持同一行、不换行，长跨页计数省略后可悬停查看全文。“批量追加标签”和“批量修改备份位置”收在“批量操作”下拉中，菜单保留原有选择状态与动作。窄窗口将撤回与手动新增作为整体移至下一行。
- 窄窗口下仓库概览的标题和导入/导出/随机漫步按钮共用顶部一行；下方左侧以两列显示四项指标，右侧显示活跃度，避免整行热力图留下大量空白。更窄时恢复上下布局；随机漫步卡片使用固定的紧凑高度，信息贴近底部，活跃度保持固定方格与最新端可见。
- 仓库搜索聚焦不使用红色外圈；库存、标签、GB 指标的普通悬浮与键盘聚焦使用中性颜色。列表与缩略图普通点击均滚动到项目详情，复制与选择手势保持独立。详情统计胶囊仅对外层添加内边距；“导入仓库”入口与确认标题保持一致。
- 仓库标签筛选固定按“全部标签、可能重复、未压缩、用户标签”排列；“未压缩”属于应用状态标签，随界面语言切换，用户标签保持原文。下拉面板最多直接展示 20 行，更多标签在面板内滚动。排序控件使用“入库时间”或“名称”与方向符号，完整含义由可访问名称保留。
- 鼠标点击分页和输入页码继续把结果区带回视野；在非输入、非弹窗环境中使用左右方向键翻页时只替换页内容，保留当前窗口滚动位置。
- 搜索与批量操作栏均滚出顶部导航下方后，仓库右下角显示“返回仓库工具栏”；点击定位搜索栏并预留导航高度，不返回概览、不改变整理状态。弹窗和引导期间隐藏；减少动态效果时立即定位。

## UI 变更检查

更新检查使用应用内模态窗口：标题和操作区固定，中间说明区域独立滚动；按版本倒序显示 `(本地版本, 最新正式版本]` 的已发布记录，保持主题、焦点返回与 Esc 关闭行为。远端说明只渲染安全文本和有限的标题、列表、加粗与代码样式，不执行 HTML。未提供当前语言分区时显示原文并明确提示，历史加载失败或超过上限时不得声称内容完整。

1. 在中文和英文下检查溢出、空态和错误态。
2. 检查窄窗口、滚动、对话框焦点和键盘操作。
3. 确认没有重复区域、重复标题和重复监听器。
4. 对数据迁移、删除和重新计算操作检查确认与恢复路径。
5. 更新 `docs/images/` 或 README 截图时，确保画面不包含真实用户资料。
6. i18n 测试同时覆盖 HTML 静态文本和典型运行时组合文本；新增队列阶段、日志或原生对话框时必须追加对应回归用例。

## 主题

主题只修改语义颜色变量，不复制页面结构。当前提供经典、白昼、黑夜、森林和暮光；新增主题必须覆盖文字、面板、字段、边框、状态色、遮罩、阴影、仓库发现卡片和活跃度色阶，并验证正文与次要文字对比度、各状态前景/背景对比度，以及浅色/深色原生控件的 `color-scheme`。活跃度遵循 GitHub 热力图的语义：零级及尚未到达的日期都显示主题对应的中性灰底，浅色主题使用中性浅灰、暗色主题使用低亮度中性深色；只有一至四级活动格使用逐级绿色。色块悬浮或聚焦显示日期和当天仓储数量，点击或按 Enter/Space 将仓库精确筛选至该入库日期，并提供可见的清除入口。零级方格必须使用主题变量，不能硬编码白色或浅绿色。主题改名时必须迁移旧的本地存储值，不能让升级用户静默回退到默认主题。
