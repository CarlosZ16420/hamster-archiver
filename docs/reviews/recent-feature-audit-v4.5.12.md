# 4.5.9—4.5.12 新功能实现审计

审计日期：2026-08-30

## 范围与方法

本轮审计覆盖 `v4.5.9` 之后到当前 `4.5.12` 主线的新增功能与修复。审计不以测试通过代替实现检查，而是逐项追踪：

1. 渲染层入口、状态显示和事件绑定；
2. preload 暴露的 IPC 能力；
3. 主进程 IPC 与原生对话框；
4. 队列、清单、重复判断和仓库存储的实际执行路径；
5. 配置默认值、保存、任务快照和重启恢复；
6. 中英文静态文案、动态文案、日志和原生窗口；
7. 自动化测试与发布脚本是否覆盖关键约束。

## 功能落地结论

| 功能 | 实现状态 | 代码级结论 |
|---|---|---|
| Windows 安装版 | 已实现 | `build:installer` 使用独立的仓库外安装包目录，按当前用户安装且卸载不删除用户数据；安装版更新走新版安装程序，便携版继续支持 ZIP 更新。 |
| 可选“需备份目录”与扫描目录 | 已实现 | 配置允许留空；扫描时无路径会先选择目录、保存并立即扫描，压缩输出仍保持必填校验。 |
| 精确重复自动跳过 | 已实现 | 只在相对路径、文件数、大小和全部 MD5 完全一致时成立；不完整 MD5 清单不会自动跳过，可选择保留或移除队列项，日志保留。 |
| 队列相似报告 | 已实现 | 前端入口、IPC、报告汇总、仓库跳转、弹窗保留、目录证据和白名单操作均有实际调用链。未生成 MD5 时只读取文件元数据，生成后复用待处理或入库清单。 |
| 红色相似与金色精确证据 | 已实现 | 名称相似和内容精确重复使用独立范围；金色证据优先于红色证据，完整项目精确重复会覆盖每个文件。 |
| 卡顿规避 | 已实现 | 默认 500 文件阈值；超阈值目录只对 200 个稳定代表文件计算 MD5；先排除极小文件，再从剩余文件中按“大文件覆盖 + 全目录均匀分布”抽样。完整归档清单与压缩内容不缩减。 |
| 性能设置随任务保存 | 已实现 | 阈值、极小文件开关和大小、简化开关写入任务快照；开始处理后不会被后续设置变化改写。 |
| 标签自动补全 | 已实现 | 单项整理和批量追加共用同一模块，中英文逗号分段，Tab/Enter 补全，已有标签去重。 |
| 用户数据区只允许安全切换 | 已实现 | 输入框只读，切换通过主进程迁移与重启流程完成，旧目录保留。 |
| 安装版与便携版数据隔离 | 已实现 | 安装版从 Windows 用户数据根解析指针；便携版从应用旁指针解析，不把用户数据打进安装包或程序替换范围。 |

未发现需求中已经声明但只有界面、没有后端实现的空壳功能。

## 本轮发现并修复的问题

1. 动态 i18n 的观察器会漏掉“刚插入的根文本节点”和根元素自身属性，导致部分队列提示、补全提示和动态按钮仍显示中文。
2. i18n 以前没有区分界面文案与用户数据，标题、标签、路径或文件名恰好等于词典词条时可能被错误翻译。
3. 队列运行中后端会拒绝全部设置修改，但错误文案只写“路径”；前端自动保存控件仍可操作，失败后还会保留未生效的视觉值。
4. 标签补全失焦关闭计时器没有在重新聚焦或重绘时取消，快速操作时新弹出的建议可能被旧计时器关闭。
5. 退出运行队列、选择 7-Zip、仓库切换、仓库导入导出和视频选择等原生窗口缺少英文分支。
6. 库内未压缩项目加入队列失败时，提示错误地断言“原文件已移动”，与真实失败原因不符。

## 仍需遵守的发布边界

- `release:local` 生成仓库外的便携 current、ZIP 和 SHA-256；安装包由 `npm run build:installer` 单独生成，两者不是同一产物。
- 卡顿规避只限制普通相似度持久保存的 MD5 数量；未抽样文件仍参与名称、路径和大小诊断。同一路径且元数据未变化的项目可复用原清单身份自动跳过，不同路径项目只有补齐双方真实 MD5 后才会判定为整项目精确重复。
- 相似度强度或白名单变化不会隐式触发全库重算；只有用户明确执行重算时才更新既有关系。
- 公开快照、公开仓库和云端 Release 不属于日常私有主线维护，必须单独获得授权。
